# مُسَمِّع — Android V1

هذه نسخة أولية قابلة للتطوير لتطبيق تسميع القرآن.

## ما يعمل الآن
- واجهة عربية RTL.
- اختيار سورة تجريبية (الفاتحة / الإخلاص).
- اختيار الآية.
- إظهار أو إخفاء نص الآية.
- طلب إذن الميكروفون.
- الاستماع باستخدام Android SpeechRecognizer عبر الإنترنت حسب خدمة الجهاز.
- مقارنة نصية أولية بين ما التقطه النظام ونص الآية.
- تحديد أول موضع اختلاف على مستوى الكلمات بصورة مبدئية.

## ما لم يُربط بعد
- قاعدة بيانات القرآن كاملة من مصدر موثوق.
- نموذج تعرف صوتي مخصص لتلاوة القرآن.
- استخراج الخطأ أثناء القراءة في الزمن الحقيقي.
- تشغيل مقطع التصحيح بصوت الشيخ محمد صديق المنشاوي.

سبب عدم تضمين ملفات المنشاوي في المشروع مباشرة: يجب أولاً اختيار مصدر تسجيلات يتيح الاستخدام داخل التطبيق والتأكد من حقوق التسجيل/الترخيص. لا ينبغي توليد صوت مقلد للشيخ.

## فتح المشروع
1. ثبّت Android Studio حديثًا (Rabbit 1 / 2026.2.1 أو ما يدعم AGP 9.4) مع JDK 17 وAndroid SDK 37.
2. افتح مجلد `Musammi_V1` كمشروع Android Studio.
3. دع Android Studio يقوم بعمل Gradle Sync وتنزيل الاعتماديات.
4. شغّل التطبيق على هاتف Android أو محاكي يدعم الميكروفون.
5. عند أول تسميع وافق على إذن الميكروفون.

## المرحلة التالية المقترحة
خادم API يستقبل مقاطع صوت قصيرة ويعيد JSON يحتوي على:
- السورة والآية والموضع الحالي.
- الكلمات المطابقة.
- أول كلمة خاطئة.
- نوع الخطأ: حذف / استبدال / إضافة / توقف.
- رابط المقطع الصوتي الصحيح المرخّص للمنشاوي.

ثم يشغّل Android مقطع التصحيح ويطلب من المستخدم إعادة القراءة.
